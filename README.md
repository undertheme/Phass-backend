# Pet2Dao Backend

# Pre-requisites
- Install [Node.js](https://nodejs.org/en/) version 16.0.0
- Install Postgresql version 14.0.0


# Getting started
- Clone the repository
```
git clone -b develop  https://github.com/topdragonmaster/backend_pet2dao.git
```
- Install dependencies
```
cd <project_name>
npm install
```
- Build and run the project
```
npm start
```
